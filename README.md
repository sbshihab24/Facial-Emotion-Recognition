# Facial Emotion Recognition using SE-CAM Enhanced CNN

This project presents a custom Convolutional Neural Network (CNN) model integrated with **Squeeze-and-Excitation (SE)** and **Class Activation Mapping (CAM)** blocks for effective facial emotion recognition. The model is trained on the **RAF-DB** dataset and demonstrates high accuracy in recognizing human facial expressions.

## 📌 Project Highlights

- ✅ Custom-built CNN architecture from scratch
- ✅ Integrated **SE Block** for channel-wise attention
- ✅ Added **CAM Block** for interpretability
- ✅ Achieved **99% training accuracy** and **95% validation accuracy**
- ✅ Trained and tested on **RAF-DB** (Real-world Affective Faces Database)

## 🧠 Technologies Used

- Python
- TensorFlow / Keras
- CNN, SE Block, CAM
- Pandas, NumPy, Matplotlib
- RAF-DB (Kaggle)
